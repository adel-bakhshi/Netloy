# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.2.0] - 2026-02-08

### Added

- Multi-target framework support for both .NET 8 and .NET 10

### Changed

- Updated project configuration to target both `net8.0` and `net10.0`
- Modified build and publish pipelines to support multiple frameworks
- Updated documentation to reflect dual framework support

### Fixed

- Resolved compatibility issues with .NET 8 runtime
- Fixed build warnings related to multi-targeting

## [1.1.0] - 2026-01-01

### Changed

- Upgraded to .NET 10

## [1.0.0] - 2025-12-19

### Added
